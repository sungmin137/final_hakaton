# 접근 13 — 개선판 라우팅 (김혜성 제안 (a)~(e) + Rim457 재판기 틀)

## 개요
9차(접근 12 v4: v4 피처 + colsample 0.7 + 3차 복원 배율, LB 0.4377)를 메인으로 고정하고, 메인이 헷갈린 행만 작은 쌍별 모델이 다시 판정한다.
접근 11 v5(라우팅, LB 0.4332)의 실패 원인 진단(쌍둥이 행 혼입, 표본 52개 과적합)을 보정한 버전. 코드: `4. src/common/approach13_routing/approach13_v1_routing.py` (train만 사용, 메인 OOF·test 확률은 9차 것을 재사용).

| 제안 | 반영 |
|---|---|
| (a) 서브모델 학습에서 쌍둥이 제외 | 완전 동일 프로필 행 1,016개 제외 후 학습 |
| (b) 소표본에 맞는 단순 모델 | 유전자 변이 유무 이진 + 변이 수, 로지스틱 회귀 L2 C=0.1, class_weight balanced |
| (c) 확신 임계값 | 서브모델 확률 ≥ conf 일 때만 덮어씀 (conf 0.5~0.8 탐색) |
| (d) test 쌍둥이 행 제외 | train과 완전 동일한 test 행(235)은 라우팅하지 않음 |
| (e) 분산 검증 | 각 fold의 임계값을 나머지 4개 fold로 고르는 교차선택 → 5개 fold 모두 (gap 0.1, conf 0.5) 선택, 결과 동일 |
| 재판 쌍(Rim457) | BRCA-OV, BRCA-PRAD, HNSC-STES, LIHC-STES, LUAD-STES, LUSC-STES, OV-PAAD + PRAD-THCA, BRCA-SARC 추가 |

## 버전

|---|---|---|---|---|
| v1 | `approach13_v1_20260911_1602` | 위 전체, gap 0.1 / conf 0.5 | 0.4847 → **0.4883 (+0.0036)**, 바뀐 행 168 | 미제출 |

## 결과 해석
- 임계값 격자 16개 모두 −0.0004 ~ +0.0036. 교차선택도 +0.0036으로 안정적이지만 **개선폭이 작다**.
- 쌍별 단독 기여는 전부 ±0.001 이내. 쌍둥이 쌍(GBMLGG/LGG +0.0002, KIRC/KIPAN +0.0004)은 쌍둥이를 빼고 단순 모델을 써도 갈릴 정보가 없음이 재확인됨.
- 표본이 충분한 상피암·BRCA 쌍도 각 +0.001 이하: 메인 XGB가 이미 유전자 유무 정보를 다 쓰고 있어, 같은 정보로 만든 재판기는 새 정보를 주지 못한다.
- LB 실행 편차(±0.015)보다 훨씬 작아 LB에서 확인 불가. 제출은 "손해 없는 소폭 변경" 정도의 기대로만.
