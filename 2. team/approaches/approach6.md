# 접근 6 — 극대화 (Maximize): 구조적 상한을 깨려는 시도들

목표: LB 0.6. 정직 CV 0.50 / LB 0.43 상태에서 남은 상한(쌍둥이 4클래스, 패널 부재 driver, test 분포 차이)을 정면으로 겨냥한 실험 모음.
코드: `4. src/common/approach6_maximize/`

## 실험 결과 (정직 CV, 기준 = approach5 OOF + 클래스 배율 0.5165)
| 번호 | 방법 | 결과 | 판정 |

## 사전 진단 (train 한 fold)
- 검증 fold 안에서 KIRC 80%, LGG 73%가 짝(상위 클래스 복사본)을 같은 fold에 가짐 → test 안에도 쌍이 많지만 어느 쪽인지 식별 불가.
- 희귀 변이(학습 fold 2~4명, 단일 클래스) 투표: 커버 14%, 정확도 53% (SKCM 98%, ACC 89%, 나머지는 모델보다 낮음).

## 결론 (진행 중)
쌍둥이·모델 다양성 축은 이득이 없었다. 남은 축은 차원 축소와 상피암 구간 개선이며, 그래도 LB 0.6은 외부 데이터 없이는 어렵다는 판단(2. team/approaches/approach5.md, 3. docs/05).
