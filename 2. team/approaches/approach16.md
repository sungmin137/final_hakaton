# 접근16 — 아미노산 필체 점수표(NB)로 v16의 저차원 스펙트럼 모델 교체

## 한 줄 요약

최신 스펙트럼 앙상블의 약한 `spec XGBoost` 파트를, 환자의 여러 아미노산 치환을 암종별 증거로 합산하는 `MultinomialNB` 점수표로 교체했다.

## 구성

기준 최신 앙상블은 `v4s 0.45 + v2 0.25 + v4sp 0.15 + spec XGBoost 0.15`였다. 접근16은 네 번째 자리를 다음처럼 바꾼다.

`v4s 0.45 + v2 0.25 + v4sp 0.15 + spectrum-profile NB 0.15`

NB 입력은 환자 한 명의 변이에서 추출한 다음 383개 비음수 횟수다.

- 방향이 있는 missense 치환 380종 (`R->H` 등)
- 기능상실(종결·frameshift) 횟수
- 동의 변이 횟수
- 기타 변이 횟수

NB는 같은 암종에서 자주 보인 필체의 로그 증거를 합산한다. 따라서 개별 피처 임계값을 나누는 XGBoost와 다른 방식으로 같은 변이 필체를 읽는다.

## 검증 — 전부 train 전용

| 검증 분할 | 기존 v16 | 접근16 NB 교체 | 변화 |
| --- | ---: | ---: | ---: |
| 저장된 정직 OOF | 0.523433 | 0.530556 | +0.007123 |
| 새 쌍둥이 그룹 Fold (seed 2718, v16 전체 재학습) | 0.500916 | 0.506398 | +0.005482 |

두 검증에서 같은 방향으로 올랐다. 가중치 탐색은 하지 않았고, 저장 OOF에서 확인한 `spec 0.15` 자리를 NB `0.15`로 한 번만 교체했다.

## 리더보드 결과

- 기준 최고점: `0.4784149`
- 접근16 쌍둥이 규칙 적용본: `0.4799` (약 `+0.0015`)

## 규칙 준수

- 점수표, 모델, 가중치, 검증 선택은 모두 `train.csv`로만 수행했다.
- `test.csv`는 검증이 끝난 뒤 최종 제출 파일을 만들 때 한 번만 transform/predict에 사용했다.
- 쌍둥이 규칙은 최종 추론에서 train과 완전히 동일한 프로필에만 적용했다.
