## 1. 문제와 규칙
- 환자별 유전자 변이 프로파일(4,384개 유전자, WT/아미노산 변이 문자열)로 암 아형 26종 분류. train 6,201 / test 2,546. Macro F1, Public LB = test 100%.
- 외부 데이터 금지, 사전학습 모델 허용, 하루 4회 제출, test 누수(test 통계로 fit·결측 처리·인코딩 등) 시 수상 제외. 준수 체크리스트 `rules_compliance.md`.
- 원칙: test.csv는 제출 스크립트의 추론 단계에서만 읽는다(`make_submission.py`가 유일한 지점).

## 2. 진행 방법 (워크플로우)
1. **정직 CV**: 같은 환자가 두 라벨로 중복된 쌍둥이(KIPAN↔KIRC 276쌍, GBMLGG↔LGG 173쌍)를 같은 fold에 묶는 `--group-twins` 5-fold. 일반 CV는 +0.05 부풀려짐.
2. **한 번에 한 요소**: 기준선 대비 요소 하나만 바꿔 제출하고, 판단은 LB로만(CV↔LB 상관 ≈ 0). 배율은 3차 복원 벡터 고정, 쌍둥이 규칙 ON.
3. **재현성**: 제출 csv = 같은 이름의 재현 스크립트(`4. src/submissions_source/approachN_vK_YYYYMMDD_HHMM.py`) 1:1. 두 번 실행해 md5 일치 확인. 실수 피처는 float64 + 반올림.
4. **기록**: 접근법마다 `approaches/approachN.md`(버전별 상세), 제출 색인 `5. submissions/README.md`, 실험 한 줄 로그 `3. docs/experiments_log.md`, 현재 상태 한 장 `STATUS.md`.
5. 팀 분담: 성민 = 주 파이프라인(접근 1·2·12·14) · 혜림 = HNSC/STES 재판기(접근 19) · 혜성 = 신장·뇌 서브모델(접근 11), 배율 재계산(접근 22).

## 4. 접근법 요약 (통한 것 / 안 통한 것)
**통한 것**
- 접근 1 클래스별 집약 점수(NB 로그우도비) 140개 — 모델 이득의 77%.
- 3차 클래스 배율(train OOF 좌표 상승, 26개) — 제출 확률에서 최소제곱 복원해 고정. 재적합(중첩 CV 포함)은 전부 열세.
- 접근 14 v2 변이 유형 분리 점수(missense/절단/동의) 모델을 9차와 로그평균 — 변이 31~100 구간 0.403→0.457, LB +0.019.
- **초과변이 규칙**(`postprocess/hypermut_rule.py`): train 변이>396 행 61개에 ACC 0인데 test에는 ACC 예측 18행(변이 900~1000, ACC 정확 표지 0~2개) → 허용 클래스 {BRCA, CESC, COAD, SKCM, STES, UCEC} 내 재선택. 31행으로 LB +0.0125.
- 쌍둥이 규칙(`postprocess/twin_rule.py`): test 행이 train 행과 동일하면 라벨 뒤집기. 13차 +0.005, 16차 위에서는 0. 동점(KIPAN·KIRC 둘 다) 무작위 버그 수정(9/13).

**안 통한 것** (정직 CV 또는 LB로 닫힘)
- 피처를 원본 열로 추가(문헌 driver, 전처리 확장 합치기, 위치 구간, 치환 성질, 공변이 쌍, 밴드별 통계) — 트리가 무시하거나 저변이 클래스 붕괴.
- 같은 정보의 다른 모델 블렌딩(접근3·5, CatBoost, 16모델 배깅, 이진 유전자 LR, 접근7 모델) — CV↑ LB↓. **16차와의 차이 = "다른 정보" vs "다른 표현"**.
- 강한 규제, 라우팅·재판기(argmax 뒤 / 확률 단계), 군집 전문가, 계층 학습(24클래스), 배율 재적합·밴드별 배율, 트리 수, 점수만 저차원 모델, 문헌 확정 마커 덮어쓰기.
- **상피 군집(STES·LUSC·HNSC·LUAD·BLCA·COAD·CESC) 재배치는 LB 손해**(19·20차 하락분 대부분). test 분포 이동의 핵심 구간이라 train CV 재배치가 안 옮겨짐.

## 5. 핵심 교훈
1. CV는 LB 절대값을 예측 못 하고(차이 −0.03~−0.08, 흔들림 ±0.02) 순위도 못 맞춘다. 판단은 LB.
2. LB를 올린 두 도약(16·21차)은 모두 **test에 많고 train에 적은 영역**(변이 31~100, >396)을 직접 다룬 것. CV에 안 보여도 train 통계 + 도메인 근거가 확실하면 LB가 오른다.
3. 새 정보는 원본 열이 아니라 클래스별 집약 점수 형태로, 그리고 합치지 말고 별도 모델로 블렌드.
4. 제출 전 점검: 바뀐 행 수·어느 클래스로 몰리는지·상피 군집 재배치 비율. 확실한 방향의 소규모 규칙이 큰 재학습보다 낫다.
