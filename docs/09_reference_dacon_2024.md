## 해석
- 이 대회 데이터는 TCGA 코호트에서 추출된 것이다 (라벨이 TCGA 코드, KIPAN/GBMLGG 합본 구조).
  → **TCGA 원본 변이 데이터를 외부 데이터로 쓰면 test 환자의 변이 프로필과 대조해 암종을 사실상 조회할 수 있다.**
  상위권 0.65~0.77은 이 경로일 가능성이 높다. 외부 데이터 없이 0.7에 도달한 사례는 확인되지 않았다.
- 외부 데이터 없이 순수 모델링으로 기대할 수 있는 상한은 우리 분석(쌍둥이 구조, 패널 누락 유전자, 표지 없는 클래스)상 0.5 전후로 추정.

## 우리 해커톤에 주는 선택지
1. **외부 데이터 허용 여부를 규칙에서 확인**. 허용이면 TCGA MC3/cBioPortal 변이 데이터로 매칭 → 0.7+ 가능하지만 "모델 실력"이 아니며 발표에서 설명 가능해야 함.
2. 불허 또는 팀이 원치 않으면: 앙상블·쌍둥이 규칙·초과변이 처리로 0.5 안팎을 목표로 하고, 발표는 데이터 구조 발견(쌍둥이, 변이 위치, 패널 누락)을 강점으로.
