## 데이터 구조
- 6,201행 × 4,386열 = ID + SUBCLASS + **유전자 4,384개**
- 결측 없음, ID 중복 없음. 모든 값은 문자열.
- 값: `WT` (99.19%) 또는 아미노산 변이 표기. 다중 변이는 공백으로 연결 (예: `Q369* I368N`, 최대 64개).
- 전부 WT인 유전자 154개 → 정보 없음, 제거 가능.

## 변이 표기 유형 (개별 변이 255,164개)
| 유형 | 개수 | 비율 | 예시 |
|---|---|---|---|
| missense | 164,740 | 64.6% | V600E, R132H |
| synonymous (동의) | 66,883 | 26.2% | D623D, L42L |
| nonsense (종결) | 13,428 | 5.3% | R213* |

→ 동의 변이는 단백질 기능 변화가 없어 노이즈일 가능성. **"변이 있음/없음"과 "기능성 변이 있음/없음"을 분리한 피처**로 비교 실험 필요.

## 타깃: SUBCLASS 26개, 불균형
- 최다 BRCA 786 / 최소 DLBC 38 (약 20배). ACC 72, THYM 98도 소수.
- TCGA 코드 체계. **상위 집합과 하위 집합이 동시에 라벨로 존재**:
  - `GBMLGG` (461) ⊃ `LGG` (229) — LGG vs GBMLGG 구분이 핵심 난제
  - `KIPAN` (515) ⊃ `KIRC` (334)
  - `STES` (379) = STAD + ESCA (개별 라벨은 없음)
  → 이 쌍들은 변이 프로파일이 겹쳐 혼동행렬에서 집중 오분류될 것. 별도 전략(2단계 분류, 클래스 가중치, 후처리) 후보.

## 클래스별 신호
- 샘플당 변이 수 중앙값이 클래스마다 크게 다름: THYM 2, LAML 3, THCA 4 … LUSC 57, SKCM 85.5 → **총 변이 수, 유형별 개수**는 강력한 피처.
- 표지 유전자가 뚜렷한 클래스: LGG(IDH1 79%), THCA(BRAF 57%), COAD(APC 72%), KIRC(VHL 45%), LAML(NPM1 26%), SKCM(BRAF 50% + 고변이 부담).
- 대표 hotspot: R132H(IDH1), V600E(BRAF), E545K/H1047R(PIK3CA), R175H/R273C(TP53).
  → 유전자 단위 이진화만으로도 상당 성능 예상. hotspot 변이 자체를 피처로 추가하면 보강 가능.

## 미확인 (사용자 확인 필요)

- 마감일, 일일 제출 횟수.

## 모델링 방향 (초안)
1. **베이스라인**: 유전자별 이진(변이 여부) 4,230개 + 변이수/유형별 카운트 → LightGBM, Stratified 5-Fold. Macro F1·Accuracy 동시 기록.
2. **피처 v2**: 동의 변이 제외 이진화, 유형별 유전자 카운트(missense/nonsense/fs), hotspot 변이 one-hot(빈도 ≥ N).
3. **모델 비교**: LightGBM / CatBoost / XGBoost / 로지스틱(희소 행렬) / 간단 MLP → 확률 앙상블.
4. **난제 대응**: LGG↔GBMLGG, KIRC↔KIPAN 혼동 분석 후 계층 분류 또는 클래스 가중치 조정.
5. **최종**: 전체 train 재학습 → test.csv 최초 로드 → 추론 → submissions/.
