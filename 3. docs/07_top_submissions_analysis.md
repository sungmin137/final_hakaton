## 1. 공통 요소 (0.42 이상의 필요조건)
1. **피처 v4** = 유전자 이진화·카운트(기본) + 접근 1 개수 가중치 점수 + 접근 2 인사이트(hotspot 위치·LoF·조합·특수그룹) + BLOSUM62 지식. 여기서 피처를 더하면(접근 4·5·7·8) 전부 0.42 아래.
2. **3차 배율 벡터** (STES 0.5, BRCA 0.5, SKCM 0.5, THCA 0.5, COAD 0.5 / SARC 3.0, THYM 2.5, KIRC 2.5, LUSC 2.0, PRAD 2.0, DLBC 2.0 …). 배율 없는 제출(4차 0.403, 7차 0.397)과 재생성 OOF 배율(STES 0.85)을 쓴 8차 초기본은 모두 낮음.
3. **XGB 공식 파라미터 또는 가벼운 colsample(0.7)**. 규제를 세게 하면(11차 0.411) 손해.
4. 쌍둥이 규칙은 있어도 없어도 차이 없음(6~10행).

→ **효과의 정체는 "큰 클래스(STES·BRCA·HNSC)로 쏠린 예측을 SARC·LUSC·LUAD·PRAD·KIPAN으로 돌린 것"**이며, 이것을 해낸 장치가 3차 배율 벡터다. Macro F1은 26개 클래스 평균이라 소수·저재현 클래스의 recall을 사는 쪽이 유리하다.

## 3. 상위 4개 파일끼리의 차이
- 4개 모두 같은 답을 낸 행 1,764개(69%). 하나라도 다른 행 782개(31%)가 실행·설정에 따라 흔들리는 경계 행.
- 다수결(consensus)과의 거리: 3차 147행, 10차 229행, 9차 300행, 8차 425행. **3차가 상위 4개의 중심**에 있고, 점수는 중심 거리와 무관(9차가 최고).
- 서로 다른 행은 STES↔LUSC↔HNSC↔LUAD↔BLCA(상피암) 사이와 SARC↔PRAD↔BRCA 사이의 이동이 대부분.

## 4. 김혜성 님 12차(라우팅 0.4332)에서 배울 것
- 9차 설정에 GBMLGG/LGG 전용 서브모델을 얹었더니 −0.0046. 원인 진단(회의 자료 9/11): LGG를 진짜로 학습할 비쌍둥이 행이 52개뿐이고, 서브모델 학습에 쌍둥이 352행(같은 입력·다른 정답)이 섞여 노이즈를 외움.
- 제안된 보정 5가지: (a) 서브모델 학습에서 쌍둥이 제외, (b) 52표본에 맞는 단순 모델(로지스틱+강한 L2), (c) 서브모델이 확신할 때만 덮어쓰기(임계값), (d) train 쌍둥이가 있는 test 행은 라우팅 제외, (e) 시드 반복 CV로 분산 확인 후 제출.

## 5. 결론 — 점수를 올릴 여지가 있는 곳
1. **경계 행 782개의 정확도**: 상위 파일들이 서로 다르게 답한 행. 여기서 맞는 쪽을 고르는 장치가 필요하며, 라우팅(혜성 님 제안 (a)~(d))이 그 후보.
2. **라우팅 대상 확장**: GBMLGG/LGG·KIRC/KIPAN는 쌍둥이 때문에 상한이 낮다. 표본이 충분한 혼동 쌍(HNSC↔STES 62건, PRAD↔THCA 63건, BRCA↔OV 141건, BRCA↔PRAD 134건)에 같은 틀(비쌍둥이 학습 + 단순 모델 + 임계값)을 적용하는 편이 기대값이 높다. Rim457 님 접근 10(재판기, CV +0.0066)이 이미 이 방향.
3. 배율·피처·규제는 상한에 닿았으므로 손대지 않는다(9차 설정 고정).

## 6. 어떤 피처가 점수를 만들었나 — 9차 설정 모델의 피처 묶음별 기여 (total_gain)
| 묶음 | 열 수 | 분기에 실제 쓰인 열 | 기여 |
|---|---|---|---|
| **접근 1 변이 단위 점수 (cw_variant_*)** | 84 | 84 | **40.7%** |
| **접근 1 유전자 단위 점수 (cw_gene_*)** | 56 | 56 | **36.2%** |
| 접근 2 BLOSUM62·아미노산 특성 (kf_*) | 68 | 68 | 9.2% |
| 유전자 변이 유무 (g_*) | 4,230 | 1,326 | 6.5% |
| 변이 개수·유형 비율 (n_*, log, ratio) | 13 | 13 | 4.8% |
| 접근 2 기능상실 유전자 (lof_*) | 1,570 | 67 | 2.4% |
| 접근 2 hotspot 위치 one-hot (hs_*) | 429 | 34 | 0.1% |
| 접근 2 동반 조합 (combo_*) | 14 | 9 | 0.1% |
| 특수그룹 플래그 | 2 | 1 | 0.0% |

- **점수의 77%는 접근 1의 클래스별 개수 가중치 점수(140개)**에서 나온다. 상위 25개 피처 중 21개가 cw_*. 이 점수는 "이 환자의 변이들이 각 암종에서 얼마나 자주 나왔나"를 변이 위치 단위(nb·count·rate)와 유전자 단위(spec·rate)로 요약한 것이다.
- BLOSUM 지식 피처(9.2%)와 변이 개수(4.8%)가 그다음. 유전자 유무 4,230열은 다 합쳐도 6.5%.
- **hotspot one-hot(429열)과 동반 조합(14열)은 0.1%**로 사실상 무시된다. 같은 정보가 cw_variant 점수에 이미 집약돼 있어 트리가 원본 열을 쓸 이유가 없다. 이것이 "피처를 더해도 CV만 오르고 LB는 안 오르는" 구조의 원인이다: 새 피처는 기여가 작거나 cw_ 점수와 중복이다.

- SARC는 재현율 0.36인데 정밀도 0.12 → 배율 3.0이 다른 저변이 암종(PRAD·OV·LIHC·CESC)의 애매한 행을 끌어온다. **SARC·PRAD·PCPG·THYM·OV는 서로 뒤엉킨 "저변이·무표지 군집"**이고, 이 군집 안의 구분이 Macro F1을 가장 많이 깎는다(5개 클래스 평균 F1 0.30).
- 상피암 군집(STES·LUSC·HNSC·LUAD·BLCA)은 두 번째 손실원. test에 2.4배 많다.

## 8. 방향 결론 — 접근법과 피처 엔지니어링을 어디에 걸 것인가
1. **접근 1 점수(cw_)를 고도화하는 것이 가장 지렛대가 크다.** 점수의 77%를 이 140개가 만들고 있다. 후보: (i) 변이 유형별(missense/LoF/동의) 분리 점수, (ii) 위치 구간(도메인) 단위 점수 — 정확히 같은 위치가 아니라 근처 위치도 묶어 세기(hotspot one-hot이 못 쓰인 이유는 너무 희소해서다; 구간 단위로 묶으면 cw_ 점수 형태로 흡수 가능), (iii) 저변이 군집 전용 점수 — SARC·PRAD·PCPG·THYM·OV만 놓고 계산한 상대 점수.
2. **원본 열을 늘리는 피처(hs_, combo_, 유형 분리 이진화, 문헌 one-hot)는 트리가 안 쓴다.** 접근 4·7이 CV만 올리고 LB에서 진 이유. 새 정보는 반드시 **cw_ 형태의 집약 점수**로 넣어야 한다.
3. **배율은 유지하되 SARC 3.0의 부작용을 인지.** 저변이 군집 안에서의 정확도가 오르면 SARC 정밀도가 회복되고 PRAD·OV·PCPG·THYM도 같이 오른다.
4. 쌍둥이 4클래스와 PAAD는 정보 부재라 손대지 않는다.
