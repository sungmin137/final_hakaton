CV 기준 예상: Macro F1 약 0.49 / Acc 약 0.53 (5-Fold OOF). 리더보드 점수는 제출 후 `3. docs/experiments_log.md`에 기록.

## test 단계에서 관찰한 것 (추론 시점의 피처 관찰, 라벨 없음)
1. **결측 셀 237개(128행, 25열)** — train에는 없음. WT로 간주 (`load_test`에서 fillna). CNOT2 77개, TNFAIP6 65개에 집중.
2. **train과 완전 동일한 행 235개 (9.2%)**. 쌍둥이 규칙이 적용 가능한 행이지만, v2 XGB가 이미 같은 패턴을 학습해 실제로 바뀐 예측은 10행뿐.
3. **⚠️ 분포 차이**: test 변이수 중앙값 28 (train 14), 변이 300개 초과 142행 = 5.6% (train 1.6%). test에 초과변이 샘플이 3배 이상 많다.
   → 모델이 **STES를 21.5%로 과잉 예측** (train 비율 6.1%). 초과변이 샘플을 STES/SKCM/UCEC 중 STES로 몰아넣는 것으로 보임.
   → 이 차이를 test로 보정하는 것은 규칙 위반이므로 하지 않았다. 대신 train 안에서 초과변이 샘플의 분류를 개선하는 것이 다음 과제.
4. 예측 확신도 중앙값 0.49, 절반은 0.5 미만 → 확신 낮은 구간이 넓다. 앙상블/캘리브레이션 여지.

## 5차 제출 후 진단 (LB 0.417, 2026-09-09 저녁)
정직 CV는 0.4486 → 약 0.49로 올랐는데 LB는 0.41 → 0.417. 5차와 1차의 예측이 다른 행이 787개(31%)인데 점수는 0.007만 변함.
→ CV 개선이 test로 옮겨지지 않는다 = **test가 train과 다른 분포**.

| 변이수 구간 | train 비율 | test 비율 |
|---|---|---|
| 1-10 | 39% | 23% |
| 11-30 | 38% | 28% |
| **31-100** | **16%** | **38%** |
| 101-300 | 5% | 4% |
| >300 | 1.6% | 5.6% |

- test는 변이 31~100개 구간이 train의 2.4배. 이 구간은 STES/LUSC/HNSC/SKCM/LUAD/BLCA/LIHC가 뒤섞인 곳이고, train OOF에서도 이 구간의 STES 정밀도가 0.46에 불과하다(예측 291 중 실제 134).
- 이 구간을 잘 가르는 것이 LB에 가장 직접적으로 반영될 가능성이 높다. → 접근3 v4: 중간 부담(31~300) 전용 전문가 실험.
- ⚠️ 규칙: test 분포를 보고 **모델을 조정하지는 않는다**. v4 전문가는 train만으로 학습하고 라우팅 기준도 샘플 자신의 변이 개수(피처)다. 다만 "이 구간을 파야 한다"는 우선순위 판단은 test 예측 분포 관찰에서 왔음을 기록해 둔다.
