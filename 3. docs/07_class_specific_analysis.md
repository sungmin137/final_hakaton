# 클래스별 개선 시도 기록

각 클래스(또는 쌍둥이 문제로 엮인 클래스 쌍)마다 시도한 것 · 결과 · 채택 여부와 이유를 기록한다.
상세 실험 로그는 `2. team/approaches/approach11.md`(쌍둥이 문제 클래스) 등 관련 approach 문서에 남기고,
여기는 **클래스 기준으로 재정리한 요약**이다. 형식: 시도 → 결과 → 채택 여부(이유).

---

## GBMLGG / LGG (뇌종양: 교모세포종+저등급 신경교종 / 저등급 신경교종)

**클래스 구성**: GBMLGG 461행(쌍둥이 175=38.0%, 비쌍둥이 286), LGG 229행(쌍둥이 177=77.3%, 비쌍둥이 52)
**패널 한계**: 핵심 마커 1p/19q 동시결실은 데이터 형식상 표현 불가. CIC/FUBP1(대리 마커)도 패널에 없음.

| 시도 | 방법 | 결과 | 채택 여부(이유) |
|---|---|---|---|
| 전용 서브모델(고차원) | XGBoost, 전체 피처(수천 차원), 쌍둥이 포함 학습 | GBMLGG 재현율 92%, LGG 재현율 32.7% | 라우팅 앙상블(v4) 재료로만 사용 |
| 라우팅 앙상블(고차원) | v4 로직을 실제 test에 적용(v5) | 정직CV +0.0024, **LB 0.4331(v7 대비 −0.0046, 역효과)** | 미채택 — CV↔LB 무상관 |
| 쌍둥이 제외+단순모델+임계값(v6) | 로지스틱회귀, 쌍둥이 제외, 신뢰도 임계값 | 5시드 CV 평균 개선 +0.0001~0.0005(표준편차 0.006보다 작음, 노이즈) | 미채택 — CV 자체에서 신호 없음 |
| **저차원 마커(v7)** | IDH1/EGFR/ATRX/PTEN/IDH2/TP53 6개, 로지스틱회귀 | **이진분류 macro F1 0.7295**, LGG 재현율 32.7%→**78.8%** | **채택** — 지금까지 최선, 26클래스 통합 테스트 진행 중 |
| 평가방식(LOOCV vs 5-fold) | v7 기준으로 비교 | 0.7295 vs 0.7147~0.7295, **거의 동일** | 5-fold(+반복시드)로 충분 확인 |
| 마커확장/조합피처/임계값(v8) | 마커 6→10개, IDH1&ATRX 조합, 임계값 0.4~0.7 | 전부 기준(0.7224)과 통계적으로 동일(0.714~0.725) | 미채택 — 정밀도(45%)가 안 움직임, 생물학적 한계로 추정 |
| 비선형모델(v9a) | SVM(RBF), 결정나무 | 0.7006 / 0.7100 — **기준보다 나쁨** | 미채택 — 표본 적어 불안정 |
| 카이제곱 자동탐색(v9b) | 전체 4,384유전자에서 top-6 자동선정 | 0.7064 — 기준보다 나쁨(문헌마커가 통계적으로도 확인됨) | 미채택 — 노이즈에 취약 |
| 변이 심각도(v9c) | 이진 대신 BLOSUM62 심각도 점수 | 0.7237 — 기준과 통계적으로 동일 | 유의미한 차이 없음 |

**결론**: 저차원 마커(v7) 구성이 최종안. 정밀도 45% 한계는 "GBMLGG 라벨이 생물학적 하위분류가 아니라 코호트 소속을 나타내는 것"이라는 구조적 문제로 추정, 추가 튜닝으로 못 넘음. **다음 단계: 26클래스 메인 파이프라인 통합 테스트(진행 중), twin_rule 동시 비교.**

## KIRC / KIPAN (신장암: 신장 투명세포암 / 신장암 전체)

**클래스 구성**: KIRC 334행(쌍둥이 276=**82.6%**, 비쌍둥이 58), KIPAN 515행(쌍둥이 277=53.8%, 비쌍둥이 238)
**패널 한계**: 핵심 driver 유전자 PBRM1/SETD2/BAP1 전부 패널에 없음. VHL/MET만 존재.

| 시도 | 방법 | 결과 | 채택 여부(이유) |
|---|---|---|---|
| 전용 서브모델(고차원) | XGBoost, 전체 피처, 쌍둥이 포함 | KIRC 비쌍둥이 정확도 17~21% | 근거 부족으로 라우팅 대상에서 제외(approach11 v2/v3 단계에서 이미 판단) |
| **저차원 마커(v10)** | VHL/MTOR/TP53/PTEN/MET/NF2/FH/PIK3CA/TSC1/CDKN2A 10개, 로지스틱회귀 | 5-fold macro F1 0.6116, **LOOCV macro F1 0.5872**(더 신뢰할 값) | 개선은 있으나(기준선 0.446 대비) GBMLGG/LGG만큼 크지 않음 |
| 비선형모델(v10b) | SVM(RBF), 결정나무 | 0.5872 / 0.6298(5-fold 기준) | 결정나무가 근소 우위였으나 LOOCV 재검증 필요 |
| 카이제곱 자동탐색(v10b) | 전체 4,384유전자에서 top-10 자동선정 | 0.6260(5-fold 기준) | 근소 개선, LOOCV 미확인 |
| 조합피처+임계값(v10c) | VHL&~MET/MET&~VHL 조합, 임계값 0.4~0.7 | 임계값0.4 붕괴(0.3509, KIRC 소수클래스라 민감), 임계값0.6 최선(0.6250, 5-fold 기준) | 5-fold 기준으로는 근소 개선이나 LOOCV로 재검증 필요 |
| 평가방식(LOOCV vs 5-fold) | v10 기준으로 비교 | **0.5872 vs 0.6116 — GBMLGG/LGG와 달리 유의미한 차이(−0.024)** | **LOOCV 값을 공식 수치로 채택**. 신호가 약할수록(VHL 45%/30% vs IDH1 41%/78.6%) 평가 방식에 더 민감함을 확인 |

**결론**: 저차원 마커가 XGBoost보다는 낫지만(17~21%→34.5%), **KIRC의 82.6%가 쌍둥이라서 마커 기반 접근이 건드릴 수 있는 영역 자체가 전체의 5분의 1도 안 됨.** LB 개선의 핵심 레버는 서브모델이 아니라 **twin_rule이 이 클래스 쌍에서 제대로 작동하는지**로 판단됨. **서브모델 추가 튜닝은 우선순위를 낮추고, twin_rule 검증에 집중 권장.**

## 방법론 메모 — LOOCV vs 5-fold, 언제 어떤 걸 쓰나
GBMLGG/LGG(LGG 52개)에서는 LOOCV와 5-fold가 거의 동일했지만, KIRC/KIPAN(KIRC 58개, 오히려 표본이 더 많음)에서는 유의미하게 달랐음(−0.024). **표본 수가 아니라 "마커 신호의 강도"가 원인으로 추정** — IDH1처럼 신호가 강하면 fold 구성과 무관하게 안정적이지만, VHL처럼 신호가 약하면 fold 구성(운)에 따라 크게 흔들림.

**개정된 규칙**: 표본이 100개 미만인 서브모델은, 본 계산 전에 LOOCV와 5-fold를 둘 다 빠르게 돌려서 비교한다. 차이가 크면(대략 0.02 이상) **LOOCV 값을 공식 수치로 채택**한다. 표본 수 단독 기준(예: "30개 미만")은 절대적 기준으로 쓰지 않는다 — 신호 강도는 미리 알 수 없어서, 매번 실제로 비교해보는 것이 유일하게 믿을 수 있는 방법.

## (템플릿) 다른 클래스 작성 시 참고
- 클래스 구성(표본 수, 쌍둥이 비율 — 관련 있으면)과 패널 한계(관련 알려진 마커 중 없는 것)부터 명시
- 시도한 것마다: 방법 → 결과(정직 CV, 가능하면 LOOCV까지) → 채택 여부와 이유
- 노이즈 수준 판단 기준: 반복 시드 표준편차(대략 0.006)보다 작은 차이는 "유의미한 차이 없음"으로 기록
- LB까지 제출한 경우 LB 점수와 CV 대비 격차도 기록
