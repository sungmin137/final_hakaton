# ⚠️ 중복 샘플("쌍둥이") 발견 — 2026-09-09, train.csv만 분석

## 사실
- train 6,201행 중 **1,016행이 다른 행과 4,384개 유전자 값이 완전히 동일**하다 (451개 그룹).
- 그중 대부분은 **같은 환자가 상위/하위 라벨 두 개로 들어간 것**:
  - KIPAN ↔ KIRC 동일 쌍 **270개** → KIRC의 82%가 KIPAN에 똑같은 행을 가짐
  - GBMLGG ↔ LGG 동일 쌍 **173개** → LGG의 75%가 GBMLGG에 똑같은 행을 가짐
- 원인: TCGA에서 KIPAN = KIRC+KIRP+KICH, GBMLGG = GBM+LGG 인데 대회 데이터가 상위/하위 코호트를 각각 뽑아 합치면서 같은 환자가 두 번 들어감.
- 그 외: 변이 0개(전부 WT) 행 94개가 서로 동일(THYM 30, THCA 18, LAML 12…). LAML 내부 중복 몇 개.

## 5-Fold 검증에서 확인한 것
검증 행 중 12.1%(748명)는 학습 fold에 완전 동일한 행이 있다. 그 행의 라벨을 보면:

| 학습 fold에 있는 쌍둥이 라벨 | 검증 행의 실제 라벨 | 정확도 |
|---|---|---|
| KIPAN | KIRC | 228/230 (99%) |
| KIRC | KIPAN | 228/229 (100%) |
| GBMLGG | LGG | 131/131 (100%) |
| LGG | GBMLGG | 131/131 (100%) |
| LAML / THCA | 같은 라벨 | 26/27 |

→ **"쌍둥이가 KIPAN이면 나는 KIRC, 쌍둥이가 KIRC면 나는 KIPAN"** (LGG/GBMLGG도 동일) 규칙이 99.5% 맞는다.
같은 환자가 같은 라벨로 두 번 들어간 경우는 거의 없기 때문이다.

## v2(접근 1 피처)의 점수 상승 원인
| | 쌍둥이 있는 행 정확도 | 쌍둥이 없는 행 정확도 |
|---|---|---|
| v1 XGB | 10.3% | 43.1% |
| v2 XGB | **96.7%** | 46.6% |

- variant 단위 개수 가중치 점수는 희귀 변이 조합까지 그대로 세기 때문에, 쌍둥이가 있으면 상대 라벨 점수가 극단적으로 커진다. XGB가 "KIPAN 점수가 극단적이면 KIRC" 패턴을 학습했다.
- 즉 **+0.11 중 대부분은 중복 구조 학습**, 순수 피처 개선 효과는 쌍둥이 없는 행에서 +3.5%p.
- 명시적 쌍둥이 규칙을 v2 위에 얹으면 0.4942 → 0.4968 (이미 XGB가 대부분 학습해서 추가 이득은 작음).
- v1 + 쌍둥이 규칙만으로도 0.3845 → 0.4543.

## test에도 적용되는가
test.csv는 열지 않았으므로 확인 불가. 다만 train 안에서 상위/하위 코호트가 독립적으로 섞여 있으므로, 랜덤 분할된 test의 KIRC/LGG 샘플도 상당수가 train의 KIPAN/GBMLGG 행과 동일할 가능성이 높다. 최종 추론 단계에서 "test 행과 완전 동일한 train 행" 수를 세면 확인된다 (test 라벨을 쓰는 것이 아니라 test 피처를 train 행과 대조하는 것 — 추론 단계에서만 수행).

## 판단 필요 (사용자/팀)
1. **쌍둥이 규칙을 최종 제출에 쓸 것인가.** 대회 규칙상 제공된 train만 쓰는 것이므로 보통 허용되지만, "모델의 실력"이 아니라 "데이터 구성의 허점"이다. 팀이 발표에서 설명할 수 있어야 한다.
2. 쓰지 않는다면 v2 피처도 이 패턴을 간접 학습하므로, **쌍둥이를 제거한 CV**로 실제 모델 실력을 별도로 측정해야 한다.
3. 쓴다면 제출 스크립트가 함께 만드는 `5. submissions/…_twin_rule.csv`를 제출 (기본 제출본은 미적용).

## 구현

## 추가 (리더보드 0.41 이후): 정직한 CV 도입
`--group-twins` 옵션: 완전 동일 행을 같은 fold에 묶는 StratifiedGroupKFold. 쌍둥이 학습 효과가 사라진 "실력" 점수.

| 모델 | 일반 CV | 정직 CV (쌍둥이 그룹) | 리더보드 |
|---|---|---|---|
| v1 | 0.3845 | 0.3979 | - |
| v2 | 0.4942 | **0.4486** | **0.41** |

- v2의 접근 1 점수는 쌍둥이 효과를 빼도 v1 대비 **+0.05** 진짜 개선.
- 남은 격차 0.04는 test의 분포 차이(초과변이 3배, STES 과잉 예측)와 public 리더보드 표본 크기로 추정.
- **앞으로 모든 실험은 정직 CV(`--group-twins`)를 기준으로 비교한다.**
