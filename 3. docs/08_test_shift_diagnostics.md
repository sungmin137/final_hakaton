# 08. test 분포 이동 진단 (2026-09-14) — 21차 이후 "train에 없는 조합" 탐색의 근거

기준: 16차 블렌드의 train OOF 예측 vs 21차 test 예측. test 라벨은 없으므로 **예측 분포끼리** 비교한다(모델 행동 비교, test 통계로 무언가를 fit하지 않음).

## 변이 수 밴드 분포
| 밴드 | train 행(%) | test 행(%) |
|---|---|---|
| 0~10 | 2,488 (40.1) | 622 (24.4) |
| 11~30 | 2,333 (37.6) | 711 (27.9) |
| **31~100** | 993 (16.0) | **969 (38.1)** |
| 101~396 | 326 (5.3) | 125 (4.9) |
| **>396** | 61 (1.0) | **119 (4.7)** |

test는 층화 무작위 분할이 아니다(클래스 구성 자체가 다를 가능성). 초과변이 규칙(21차 +0.0125)이 통한 이유가 >396 밴드의 4.7배 차이.

## 31~100 밴드: 클래스별 예측 비율 (OOF → test)
- STES 16.8% → **38.2%** (+21pp), COAD 3.5 → 8.6, KIPAN 2.2 → 3.5
- LUSC 24.8 → 16.9, SKCM 9.8 → **3.5**, UCEC 4.3 → 0.6, HNSC 8.5 → 5.7
- train에 없는 클래스가 예측된 경우는 없음(THCA·LAML·LGG·THYM·TGCT·PCPG 모두 0).

## 101~396 · >396 밴드
- SKCM: OOF 32.8% → test 16.0% (101~396), train 28% → test 예측 2% (>396). **SKCM이 모든 고변이 밴드에서 test 예측 절반 이하.**
- STES: 17.8 → 27.2 (101~396).

## 전체
- STES train 6.1% / OOF 예측 4.7% / **test 예측 18.2%**. SARC·PRAD는 OOF 10%대 과잉 예측이 test에서는 5~6%(저변이 행이 적어서).
- 저변이 밴드(0~10, 11~30)에는 train에 없는 클래스 예측 없음. KIPAN이 11~30에서 15 → 21%.

## 해석과 한계
- 19차(→STES 41행 유입, −0.0136)와 20차(STES→LUSC·COAD 유출, −0.0081)가 **둘 다** 하락 → "STES가 과잉"이라는 단순 해석은 성립하지 않는다. STES 비율 자체가 아니라 어느 행을 옮기느냐가 문제이고, train CV로는 그 행을 고를 수 없다.
- SKCM 부족은 (a) test에 SKCM이 실제로 적거나 (b) 모델이 SKCM 고변이(UV형)를 STES/LUSC로 보내는 것. train 근거(BRAF V600·NRAS Q61 등 SKCM 마커를 가진 STES 예측 행)로 (b)를 점검 → `approach14.md` 후속.
