# 접근17 v2 — 선택적 아미노산 필체 보조 모델

## 한 줄 요약

기존 v16이 **답을 망설이는 환자**에서만, 아미노산 치환의 방향을 읽는 NB 보조 모델의 의견으로 바꾼다.

## 왜 필요한가

접근16 v1은 모든 환자에게 NB를 같은 비율(0.15)로 섞었다. NB는 여러 약한 아미노산 치환 단서를 합산하는 데 강점이 있지만, 모든 환자에서 기본 XGBoost 앙상블보다 낫지는 않다. 따라서 "어느 모델을 누구에게 믿을지"를 분리했다.

## 고정한 규칙

기본 v16 확률과 NB 교체 앙상블 확률을 각각 만든다.

1. 기본 v16의 보정 후 1등 확률과 2등 확률의 차이가 `0.18` 이하이면, 기본 모델은 망설이는 것으로 본다.
2. NB 단독 확률의 1등과 2등 차이가 `0.10` 이상이면, NB는 어느 정도 확신한 것으로 본다.
3. 두 조건을 **모두** 만족하는 환자만 `spec XGBoost` 대신 `spectrum-profile NB`를 사용한 앙상블 확률로 교체한다.
4. 나머지 환자는 기존 v16 예측을 유지한다.

즉, "기본 탐정이 자신 없고 보조 탐정이 자신 있을 때만 답을 다시 고친다"는 규칙이다.

## 검증 — train만 사용

기본 v16의 OOF 확률과 NB OOF 확률을 사용했다. 쌍둥이 행은 같은 묶음에 넣은 `StratifiedGroupKFold`로 5개 메타 분할을 만들었다. 각 분할에서는 4개 묶음에서만 후보 임계값을 고르고, 남은 1개 묶음에서 채점했다.

후보는 기본 모델 margin `{0.08, 0.12, 0.18, 0.25}`와 NB margin `{0.05, 0.10, 0.20}`의 작은 고정 격자였다. 다섯 번의 독립 분할에서 반복적으로 선택된 값이 `(0.18, 0.10)`이었다.

| 메타 분할 seed | 기본 v16 Macro F1 | 선택적 결합 Macro F1 | 변화 |
| ---: | ---: | ---: | ---: |
| 917 | 0.523433 | 0.531194 | +0.007761 |
| 2026 | 0.523433 | 0.530895 | +0.007461 |
| 73 | 0.523433 | 0.531797 | +0.008364 |
| 314 | 0.523433 | 0.530000 | +0.006566 |
| 2718 | 0.523433 | 0.531797 | +0.008364 |

모든 분할에서 같은 방향으로 개선됐다. 최종 test 추론에서는 이 값들을 다시 탐색하지 않고 그대로 고정했다.

## 최종 제출 생성

- 기본 구성: `v4s 0.45 + v2 0.25 + v4sp 0.15 + spec XGBoost 0.15`
- 보조 구성: `v4s 0.45 + v2 0.25 + v4sp 0.15 + spectrum-profile NB 0.15`
- 고정 gate에 걸린 test 환자: 739 / 2,546명
- 마지막에 train과 완전히 같은 변이 프로필에만 쌍둥이 규칙 적용: 235명

## 규칙 준수

임계값 탐색, OOF 평가, 모델 학습은 모두 `train.csv`로만 수행했다. `test.csv`는 최종 CSV를 만드는 `predict` 단계에서만 읽었으며, test의 분포·예측 비율·정답 추정에는 사용하지 않았다.
