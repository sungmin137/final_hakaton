# 접근 14 — HNSC↔STES 보조 판별 + 쌍둥이 규칙

## 한 줄 요약

기본 V7 모델의 예측은 유지하되, **HNSC와 STES를 헷갈린 경우만** 작은 보조 모델이 다시 확인하고, 그 모델이 충분히 확신할 때만 답을 바꾼다.

## 왜 이 실험을 했나

기본 모델은 HNSC(머리·목 암)와 STES(위·식도 암)를 자주 혼동한다. 두 암종 모두 `TP53` 변이가 흔하고 변이 수가 비슷한 환자가 있어, 전체 26개 암종을 한 번에 고르는 기본 모델만으로는 미세한 차이를 놓칠 수 있다.

앞선 방식처럼 보조 모델의 답으로 무조건 바꾸면 오히려 리더보드 점수가 낮아졌다. 따라서 이번에는 **보조 모델이 70% 이상 확신하는 경우에만** 아주 적은 수의 답을 수정했다.

## 구성

1. **기본 모델**: 기존 최고 LB 설정인 V7
   - V4 피처
   - XGBoost `colsample_bytree=0.7`
   - train OOF에서 구한 class scale 적용

2. **보조 모델**: HNSC와 STES 환자만 학습한 Logistic Regression
   - 원본 유전자를 `WT / 변이 있음`으로 이진화
   - 두 암종의 변이 빈도 차이가 큰 유전자 40개만 사용
   - 강한 과적합 방지를 위해 단순한 L2 로지스틱 회귀 사용 (`C=0.1`)

3. **부드러운 수정 규칙**
   - 기본 모델의 답이 HNSC 또는 STES일 때만 보조 모델을 본다.
   - 보조 모델의 확률이 `0.70 이상`일 때만 답을 바꾼다.
   - 애매하면 기본 모델의 답을 그대로 둔다.

4. **쌍둥이 규칙**
   - train의 유전자 변이 그림과 test의 그림이 완전히 같으면, 기존 쌍둥이 규칙을 별도 제출본에 적용한다.
   - 규칙 적용 여부는 팀의 공정성 판단에 따라 선택한다.

## 정직 CV 반복 검증 결과

고정한 보조 모델 설정을 서로 다른 3개의 `StratifiedGroupKFold` 분할에서 다시 검증했다. 완전히 같은 유전자 그림(쌍둥이)은 같은 fold에 묶었다.

| 분할 seed | 기본 V7 + class scale | 접근12 보정 후 | Macro F1 변화 | 바뀐 환자 수 |
| ---: | ---: | ---: | ---: | ---: |
| 13 | 0.49478 | 0.49536 | +0.00058 | 11 |
| 77 | 0.50281 | 0.50304 | +0.00024 | 9 |
| 202 | 0.50019 | 0.50072 | +0.00053 | 11 |
| 평균 | - | - | **+0.00045** | 약 10 |

세 분할에서 모두 같은 방향으로 아주 작게 상승했다. 큰 개선은 아니지만, 무작정 많이 고치지 않고 위험을 낮춘 미세 보정이다.

## 팀원이 다음으로 건드려 볼 수 있는 지점

- 보조 모델의 확신 기준을 `0.6`, `0.7`, `0.8`로 비교
- 상위 유전자 수를 20·40·60개로 비교
- HNSC↔STES 외 다른 혼동 쌍에도 **동일한 반복 검증 절차**를 적용

단, test 예측 분포나 test의 정답 없는 통계를 보고 기준을 정하면 안 된다. 모든 설정 선택은 train의 검증 결과만으로 해야 한다.
